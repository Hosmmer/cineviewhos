# i18n — CineViewHos Frontend

## Setup

```typescript
// main.tsx
import { IntlProvider } from "react-intl";
import { es } from "@/i18n";

<IntlProvider locale="es" messages={es}>
  <App />
</IntlProvider>
```

## Message Files

```
src/i18n/
├── index.ts    # exports { es, en }
├── es.json     # Spanish translations
└── en.json     # English translations
```

## Key Format

Dot-notation keys: `"NAV.HOME"`, `"HOME.TITLE"`, `"COMMON.LOADING"`.

## Current State

i18n infrastructure exists but messages are empty (`{}`). Strings are hardcoded in Spanish. When adding i18n:

1. Add keys to `es.json` and `en.json`
2. Use `<FormattedMessage id="KEY" />` or `intl.formatMessage({ id: "KEY" })`
3. Do NOT change existing hardcoded strings without explicit approval
